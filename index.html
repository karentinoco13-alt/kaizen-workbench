Example data

Kaizen Workbench is a planning aid. Every plan is unique to the data you enter, and results are not guaranteed without proper monitoring of the whole journey.

Privacy and security

Your projects never leave this browser. There is no account, no server and no tracking. Nobody else can see what you enter, including the person who made this app.

Where your work is saved

Everything you type saves automatically about a second after each change, in this web browser's local storage on this computer only. It does not follow you to other devices or browsers.

Clearing your browser data deletes your projects. Private or incognito windows forget them when closed. Use Back up to save a copy as a file, and Restore to load it on another computer.

What is sent over the internet

Nothing you type. The page loads its fonts from Google Fonts, which, like any website, can see your IP address when the fonts load. The app is hosted on GitHub Pages, which keeps standard server logs.

Export A3 and Back up

The files download to your own device. They are not stored anywhere else.

Sharing the link

Sharing the link gives people the app, not your projects. Each person starts with the example and their own projects in their own browser.

Deleting a project

Delete removes the project from this browser for good. If you made a backup file, that file is not affected.

Delete all my data, at the bottom of this panel, removes every project and your saved language at once, after two warnings.

Feedback

Feedback is posted as a GitHub issue that you review before posting. Everything posted on GitHub is public.

Good practice

Describe customers and colleagues by role, not by name, and leave out health, financial or other personal details. The method works just as well without them.
